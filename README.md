# 2048 Game

A web-based implementation of the classic 2048 puzzle game. The objective is to slide numbered tiles on a grid to combine them and create a tile with the number 2048. This project demonstrates complex game logic matrix calculations, DOM manipulation, and modern CSS styling with animations.

## Live Preview

[View Live Preview](https://rostyslav452.github.io/2048Game/)

## Design Reference

The design and mechanics are inspired by the original 2048 game created by Gabriele Cirulli, optimized to meet modern web accessibility (WCAG AA) standards for color contrast.

## Technologies Used

- HTML5
- SCSS (Sass)
- Vanilla JavaScript (ES6+)
- Vite (Module Bundler)

## Getting Started

To set up this project locally, follow these steps:

1. Clone the repository:

```bash
git clone [https://github.com/rostyslav452/2048Game.git](https://github.com/rostyslav452/2048Game.git)
cd 2048Game
npm i
npm start
```
